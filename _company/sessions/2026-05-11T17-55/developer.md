**✨ 썸네일 마스터 컴포넌트 기술 구현 사양 (Figma to Code Specification)**

### 1. 기술 스택 제안 및 프레임워크 선택
개발팀의 효율성과 유지보수성을 고려하여, 현대적인 반응형 디자인에 최적화된 프레임워크를 제안합니다.

*   **프레임워크:** **Tailwind CSS** 또는 **Styled Components (React 환경 가정)**. (실제 구현 시 팀의 주력 스택을 확인 후 최종 결정 필요하나, 여기서는 범용적인 클래스 기반 접근을 채택합니다.)
*   **반응형 전략:** 모바일 우선(Mobile-First) 접근 방식을 채택하여 작은 화면에서부터 고통-전환-행동 흐름이 명확하게 작동하도록 설계합니다.

### 2. 핵심 컴포넌트 정의 (Component Definition)

모든 썸네일은 세 가지 레이어(`Recognition`, `Transition`, `Action`)가 명확히 분리되어야 합니다.

#### A. Layout Component: `ShockReleaseContainer`
*   **역할:** 전체 썸네일 영역을 감싸며, Deep Indigo 배경과 Aged Gold 강조를 적용하는 최상위 컨테이너.
*   **구조:** Flexbox 또는 Grid 기반으로 좌측(고통/인식)과 우측(해방/행동)의 시각적 흐름을 명확히 분할합니다.
*   **스타일 정의:**
    *   `background-color`: `#28004C` (Deep Indigo)
    *   `border`/`shadow`: 미세한 깊이감을 부여하여 고급스러움을 유지합니다.

#### B. Layer 1 Component: `PainPointRecognition` (인식 레이어)
*   **목표:** 고통/문제점을 시각적으로 인식시키는 영역.
*   **스타일 정의:**
    *   배경: Deep Indigo (`#28004C`) 유지.
    *   텍스트 스타일: Headline 폰트(Serif 계열)를 적용하며, Pain Point 키워드에 **Aged Gold** 색상을 사용하여 시각적 충격을 최대화합니다. (Layer 1 강조)

#### C. Layer 2 Component: `TransitionFlow` (전환 레이어)
*   **목표:** 인식과 행동 사이의 긴장감 있는 흐름을 유도하는 시각적 연결고리.
*   **스타일 정의:**
    *   시각적 요소: Subtle Gradient 또는 Flowing Line 효과를 사용하여 왼쪽에서 오른쪽으로 시선을 자연스럽게 이동시키는 경로를 만듭니다. (이 부분이 'Shock-Release Loop'의 핵심 움직임)

#### D. Layer 3 Component: `ActionCTA` (행동 레이어)
*   **목표:** 즉각적인 행동(클릭)을 유도하는 최종 목표 지점.
*   **스타일 정의:**
    *   배경/강조색: **Aged Gold** (`#B89A3E`)를 사용하여 가장 높은 대비와 시선을 집중시킵니다.
    *   CTA 버튼/화살표: Aged Gold 색상을 사용하여 '해방'과 '행동'을 명확하게 지시합니다.

### 3. 반응형 구현 가이드라인 (Responsive Implementation Guide)

모든 컴포넌트는 다음의 Breakpoint를 기준으로 유연하게 조정되어야 합니다.

| 화면 크기 | 주요 조정 사항 | 목표 |
| :--- | :--- | :--- |
| **Mobile (<600px)** | 수직적 흐름 강조. 텍스트는 중앙 집중형으로 배치하여 세로 스크롤 시 몰입도를 유지. 레이어 분할은 세로로 명확히 구분. | 모바일 환경에서 즉각적인 감정 전달 극대화. |
| **Tablet (600px - 1024px)** | 좌우 분할 구조를 유지하되, 여백(Padding)을 조정하여 시각적 안정성 확보. Transition Flow의 흐름이 명확하게 보이도록 조정. | 중간 해상도에서 정보 전달과 감정 유도의 균형. |
| **Desktop (>1024px)** | 좌측/우측 분할 구조를 넓게 활용. Headline 텍스트와 CTA 영역에 충분한 공간을 할애하여 고급스러운 시각적 경험 제공. | 최대 몰입도 및 브랜드 아이덴티티 강조. |
