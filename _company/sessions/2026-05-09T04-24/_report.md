## 🖼️ 썸네일 마스터 컴포넌트 (템플릿 2) 최종 디자인 사양

본 문서는 'Deep Indigo/Aged Gold' 비주얼 시스템과 '고통 $\rightarrow$ 해방' 프레임워크를 기반으로 ROI 극대화를 위해 개발팀에 전달할 Figma 구현용 최종 디자인 사양입니다.

### 1. 시각 시스템 정의 (Visual System Definition)

| 요소 | 값 / 코드 | 역할 및 적용 기준 |
| :--- | :--- | :--- |
| **배경색 (Background)** | `#303F9F` (Deep Indigo) | 콘텐츠의 깊이감, 신뢰감 부여. 전체 썸네일 영역에 적용. |
| **강조색 (Accent)** | `#C9A84E` (Aged Gold) | 해방/해결책(Solution) 영역을 시각적으로 부각하여 시선 유도. |
| **주요 타이포그래피 (Pain/Problem)** | Serif (예: Playfair Display 또는 Times New Roman 계열) | 고통, 문제 인식 영역에 사용하여 무게감과 성찰의 깊이를 표현. |
| **보조 타이포그래피 (Relief/Solution)** | Sans-serif (예: Montserrat 또는 Inter 계열) | 해방, 해결책 제시 영역에 사용하여 명확성과 접근성을 높임. |

### 2. 템플릿 2 레이아웃 상세 사양 (Layout Specification for Template 2)

**목표:** 고통(상단/좌측)에서 해방(하단/우측)으로 시선이 자연스럽게 흐르도록 설계하여 감정적 전환을 극대화합니다.

| 영역 | 비율 (가로 기준) | 배경 색상 | 타이포그래피 스타일 | 내용 구성 요소 |
| :--- | :--- | :--- | :--- | :--- |
| **A. 고통/문제 영역 (Pain Point)** | 40% (좌측 또는 상단 배치) | `#303F9F` (Deep Indigo) | Serif (Bold, 크기 강조) | 핵심 문제 키워드 제시 (예: '고통', '막힘') |
| **B. 전환/해방 영역 (Relief)** | 60% (우측 또는 하단 배치) | `#303F9F` (Deep Indigo) | Sans-serif (Bold, 크기 강조) | 해결책 예고 및 감성적 메시지 제시 (예: '해방', '자유') |
| **C. 시각적 분리선** | 전체 영역의 10% | `#C9A84E` (Aged Gold) | - | A와 B를 구분하는 명확한 대비선 역할. |

### 3. 디자인 구현 가이드라인 (Implementation Guidelines)

1.  **배경 처리:** 전체 배경은 Deep Indigo (`#303F9F`)로 설정하여 깊은 밤하늘과 같은 분위기를 조성합니다.
2.  **Pain Text Styling:** A 영역의 모든 텍스트는 Serif 계열을 사용하며, 색상은 흰색(`#FFFFFF`)으로 설정하여 어두운 배경 속에서 고통을 명확하게 인식시킵니다.
3.  **Relief Text Styling:** B 영역의 모든 텍스트는 Sans-serif 계열을 사용하며, 핵심적인 해결책 단어에만 Aged Gold (`#C9A84E`)를 적용하여 시각적 초점을 맞춥니다.
4.  **구분선 처리:** A와 B 영역 사이에는 Aged Gold(`#C9A84E`)의 얇고 명확한 수평선(혹은 대각선 분할)을 삽입하여 감정의 전환이 일어나는 지점을 강조합니다.

### 4. 개발팀 전달 사항 (For Development Team)

*   **컴포넌트 이름:** `Thumbnail_Master_Template_V2`
*   **필수 적용 속성:** 배경색, 텍스트 색상, 타이포그래피 스타일(Serif/Sans-serif), 강조색(`Aged Gold`)의 동적 적용 방식을 정의해야 합니다.
*   **핵심 목표:** 시청자가 썸네일을 보는 순간 '고통'을 인식하고 '해방'에 대한 기대감을 즉각적으로 느끼도록 레이아웃을 구성하십시오.
