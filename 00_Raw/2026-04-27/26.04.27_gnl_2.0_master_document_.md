## 🎯 채널 정체성 (Identity)

### 채널 한 줄 정의

```
"검증된 의학으로 따뜻하게 — 시니어를 위한 신뢰 가능한 건강 정보 채널"
```

### 채널 핵심 가치 4가지

```
1. 신뢰성 (Trust)
   - 5개 권위 기관 자료 기반
   - 의학 정보 정확성 우선
   - AI 정직성 공개

2. 따뜻함 (Warmth)
   - 시니어 친화 톤
   - 진심 어린 진행
   - 시청자 공감

3. 정직성 (Honesty)
   - 본인 자산 + AI 보조 명시
   - 의료인 아님 명확
   - 면책 사항 투명

4. 일관성 (Consistency)
   - 화·목·토 18:00 정기 업로드
   - 일관된 톤·형식
   - 시청자 약속 준수
```


## 📚 콘텐츠 시스템

### 1. 정라레 톤 학습 8가지 (검증 후 정식)

```
1. 제목 패턴
   "[증상] 있을 때 반드시 피해야 하는 3가지"
   - 부정형 + 숫자 = 강력 후크

2. 인트로 시점 명시
   "건강검진 결과지를 받아보셨나요"
   - 시청자 즉시 정조준

3. 본론 시작 전 용어 정리
   1분 30초 모듈
   - 시니어 시청자 부담 감소
   - 공통 출발점 형성

4. 시청자 반박 예측 화법
   "어떤 분들은 ~ 하소연 하시더라고요"
   - 공감 + 정보 결합

5. 즉시 실천 솔루션
   채당탄, 1/3 줄이기 등
   - 행동 가능한 구체성

6. 안전한 마무리
   "치료 받으셔야 하지만~병행하셔서"
   - 의료 안전성 + 자가 실천

7. 이중 후크
   "피해야 할 것 + 약 없이~"
   - 부정 + 긍정 동시

8. 차분·친근함 톤
   V2 + 본인 아바타
   - 시니어 친화
```

### 2. 인트로 7중 후크 시스템

```
1. Pattern Interrupt
   "여러분, 잠깐만요"
   - MrBeast 황금 30초 적용

2. 이중 타깃
   "약을 들고 계신가요" + "검진 직후"
   - 수용 시청자 폭 확대

3. Triple Authority
   "대한심장학회·질병관리청·WHO"
   - 권위 즉시 형성

4. Statistical Shock
   "두 명 중 한 명"
   - 충격 통계 + 개인 정조준

5. Curiosity Gap
   "단 세 가지"
   - Hormozi 후크 이론

6. Loss + Hope
   "간·신장 지친다 / 평생 깨끗"
   - Kahneman Prospect Theory

7. Time Promise
   "차 한 잔 드시면서"
   - 효도 + 시간 약속
```
