### 2.3 수정 내용

#### 수정 1: 로고몽을 메인 정중앙으로

**Before (v0.9.3)**:
```jsx
{/* 시간대 아이콘이 메인 */}
<div className="w-40 h-40 rounded-full ... text-8xl">
  <span className="anim-float">{rec.icon}</span>  {/* ☀️ */}
</div>

{/* 로고몽이 빼꼼 (보조) */}
<div className="absolute -right-16 -bottom-10 anim-peek">
  <Logomong size={200} variant="welcome" />
</div>
```

**After (v0.9.4)**:
```jsx
{/* 로고몽이 정중앙 메인 */}
<div className="relative">
  <Logomong size={180} variant="welcome" glow />

  {/* 시간대 아이콘은 우측 상단 작은 배지 */}
  <div className="absolute -top-1 -right-1 w-12 h-12 rounded-full
                  flex items-center justify-center text-2xl
                  bg-white/25 backdrop-blur-md anim-float"
       style={{
         boxShadow: '0 8px 20px -4px rgba(0,0,0,0.25)',
         border: '2px solid rgba(255,255,255,0.4)',
         animationDuration: '4s'
       }}>
    {rec.icon}
  </div>
</div>
```

**디자인 의도**:
- **로고몽이 주인공**: welcome 표정(양팔 환영)이 첫인상
- **시간대 아이콘은 보조**: 작은 배지로 정보만 전달
- **위계 명확**: 메인(180px) vs 배지(48px)

#### 수정 2: 텍스트 가독성 강화

**Before (v0.9.3)**:
```jsx
{/* 햇살이 스며드는 시간 */}
<div className="text-[10px] tracking-[0.35em] text-white/70 font-bold">
  {msg.ambient}
</div>

{/* 은혜로운 아침이에요 */}
<h1 className="font-serif-ko text-[28px] font-bold text-white">
  {msg.greeting}
</h1>

{/* 부제 */}
<p className="text-sm text-white/90">
  {msg.subtext}
</p>
```

**After (v0.9.4)**:
```jsx
{/* 햇살이 스며드는 시간 - 그림자 + 진한 흰색 */}
<div
  className="text-[11px] tracking-[0.35em] text-white font-bold"
  style={{
    textShadow: '0 2px 8px rgba(0,0,0,0.35), 0 1px 2px rgba(0,0,0,0.25)',
    opacity: 0.95
  }}
>
  {msg.ambient}
</div>

{/* 은혜로운 아침이에요 - 입체적 그림자 */}
<h1
  className="font-serif-ko text-[28px] font-bold text-white"
  style={{
    textShadow: '0 4px 16px rgba(0,0,0,0.3), 0 2px 4px rgba(0,0,0,0.2)'
  }}
>
  {msg.greeting}
</h1>

{/* 부제 - 그림자 + 95% 불투명 */}
<p
  className="text-sm text-white"
  style={{
    opacity: 0.95,
    textShadow: '0 2px 6px rgba(0,0,0,0.25)'
  }}
>
  {msg.subtext}
</p>
```

**개선 디테일**:

| 요소 | Before | After | 개선 |
|---|---|---|---|
| 색상 | text-white/70 (70%) | text-white + opacity 0.95 (95%) | +25% |
| 글자 크기 | 10px | 11px | +10% |
| 그림자 | 없음 | 두 겹 그림자 | 입체감 추가 |
| 가독성 | ❌ 묻힘 | ✅ 또렷 | 즉각 향상 |

##### 1-3. 글씨 크기 변경 시 HTML 루트에 적용

```javascript
useEffect(() => {
  if (loading) return;

  const FONT_SCALE_MAP = [0.9, 1.0, 1.2, 1.4];
  const scale = FONT_SCALE_MAP[fontSize] || 1.0;

  // HTML 루트의 font-size에 적용 (rem 단위 자동 스케일링)
  document.documentElement.style.fontSize = `${scale * 16}px`;

  // 저장
  save('fontSize', fontSize);
}, [fontSize, loading]);
```

**기술적 핵심**: `document.documentElement.style.fontSize` 한 줄로 앱 전체 크기 변화.
- HTML의 기본 `font-size: 16px` 가 모든 `rem` 단위의 기준
- 이걸 14.4px (0.9x) ~ 22.4px (1.4x) 로 동적 변경
- 앱 전체 텍스트가 자동으로 스케일링됨

##### 1-4. 토글 핸들러

```javascript
// 글씨 크기 토글 (작게→보통→크게→아주크게→다시 작게)
const handleFontSizeToggle = () => {
  setFontSize((prev) => (prev + 1) % 4);

```

## 4. 기술적 발견과 학습

### 4.1 rem 단위의 위력

**오늘 배운 것**: `document.documentElement.style.fontSize` 한 줄로 앱 전체를 스케일링할 수 있다.

```
구조:
HTML: { font-size: 16px }     ← 여기를 바꾸면
   ↓ 모든 자식 요소가 영향받음
body, div, p { font-size: 1rem }  ← 이게 모두 함께 변함
```

**왜 이게 작동하는가?**
- `rem` = root em = HTML 루트의 font-size 기준
- Tailwind의 모든 텍스트 클래스 (text-xs, text-sm, ...) 는 rem 사용
- 루트 한 곳만 바꿔도 앱 전체 자동 적용

**비교: 다른 접근 방식**
```
❌ 안 좋은 방법:
- 각 컴포넌트마다 fontSize prop 전달
- 모든 텍스트에 className 변경
- 수백 군데 수정 필요

✅ 좋은 방법 (우리 방식):
- HTML 루트의 font-size 한 곳만 변경
- 자동으로 앱 전체 적용
- localStorage로 영구 저장
```

### 4.2 Sed 명령어로 일괄 변경

```bash
# 정규표현식으로 한 번에 41곳 변경
sed -i 's/text-\[#8B7355\]/text-[#6B5640]/g' App.jsx
```

**핵심 패턴**:
- `s/찾기/바꾸기/g` - 모든 매치 치환
- `\[` `\]` - 대괄호 이스케이프 (Tailwind의 임의 색상 문법)
- `-i` - 파일 직접 수정

**왜 이게 안전한가?**
- 정확한 패턴 매칭 (실수 없음)
- 한 번에 일괄 처리 (빠름)
- 결과 검증 가능 (`grep -c` 로 카운트)

### 4.3 WCAG 접근성 표준의 의미

```
명도 대비 측정:
- Lightness (L*) 값 차이 활용
- 1:1 ~ 21:1 범위
- 높을수록 가독성 좋음

기준:
1.0 ~ 3.0   → ❌ 거의 안 보임
3.0 ~ 4.5   → ⚠️ 큰 글씨에만 사용 가능
4.5 ~ 7.0   → ✅ AA (일반 글씨 OK)
7.0 ~ 21.0  → ✅ AAA (시각 장애인도 OK)

우리 변경:
4.0 → 6.5 (AA 안전 통과)
```

### 4.4 React useEffect의 패턴

```javascript
// 패턴: 외부 상태 동기화 + localStorage
useEffect(() => {
  if (loading) return; // 초기 로딩 중에는 적용하지 않음

  // ① DOM에 적용
  const scale = FONT_SCALE_MAP[fontSize] || 1.0;
  document.documentElement.style.fontSize = `${scale * 16}px`;

  // ② 영구 저장
  save('fontSize', fontSize);
}, [fontSize, loading]);
```

**핵심**:
- `if (loading) return` - 초기 로드 시 충돌 방지
- `[fontSize, loading]` - 의존성 정확히 명시
- DOM 조작 + 저장을 한 effect에 묶음 (관련성 있음)
